# Dicionário de Dados - Empório da Música

Este documento registra o perfilamento, tipos, chaves e regras de limpeza aplicadas aos dados tabulares (CSVs) da loja Empório da Música.

*Obs: O perfilamento detalhado será preenchido na Etapa 3 (ETL e Perfilamento).*

## Tabelas Mapeadas
1. `categories` (Categorias de produtos)
2. `customers` (Clientes cadastrados)
3. `orders` (Pedidos realizados)
4. `order_items` (Itens de cada pedido)
5. `products` (Catálogo de instrumentos e acessórios)
6. `promotions` (Campanhas promocionais)
